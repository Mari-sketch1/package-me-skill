# Platform playbooks

Last research review: 2026-09-30.

Platform interfaces change. Stable strategic rules are below; volatile limits/features should be rechecked when material to the output.

## Telegram

### Stable platform reality

- Публичный канал имеет имя, public username/link, описание и аватар.
- Описание канала поддерживает до 255 символов в текущем Telegram API.
- Можно закреплять сообщения; pinned/start-here material — важная точка навигации.
- Telegram показывает `Similar Channels` для публичных каналов; Telegram описывает рекомендации как основанные на сходстве аудиторий/подписок.
- Каналы могут иметь расширенную appearance-настройку и stories, но часть функций зависит от boost level/доступности.

### Packaging job

Telegram хорошо подходит для:
- глубины;
- серийного чтения;
- длинных личных размышлений;
- последовательного знакомства с философией;
- сообщества вокруг регулярной практики/идей.

### First impression stack

1. Channel name
2. Avatar
3. Description
4. Public username/link
5. Start-here pinned message
6. First visible posts
7. Optional appearance/stories

### Name

Имя должно сохранять личность/бренд и давать достаточно тематического контекста. Не набивай keywords через запятую.

### Description

В 255 символах приоритет:

`понятная тема/вопрос → зачем читать → характер канала → identity/source, только если помогают входу → CTA`

Не повторяй название дословно.

### Pinned Start Here

Закреп может быть длиннее bio и должен отвечать:

- кто автор;
- как он пришел к теме;
- что здесь будет;
- как связана практика/философия с жизнью;
- насколько явно канал связан с Ананда Маргой;
- с каких 2–5 материалов начать;
- следующий шаг.

### Navigation

Используй только если контента достаточно:
- 3–6 стабильных рубрик/тегов;
- индекс лучших материалов;
- отдельный пост «с чего начать».

Не строи сложное меню для пустого канала.

### Optional surfaces

Stories / profile colors / wallpapers / emoji status — дополнительный слой, а не основа упаковки. Уточняй доступность в приложении.

## ВКонтакте

### Current strategic reality

В 2026 VK публично сообщала об усилении рекомендательной системы для оригинальных авторов: собственный, вовлекающий контент от первого лица получает больше возможностей для рекомендательного охвата независимо от размера сообщества.

Практический вывод: не упаковывай человека как безликий агрегатор цитат/репостов. Автор, его опыт и оригинальное объяснение должны быть заметны.

### Possible account forms

- личная авторская страница;
- сообщество;
- связка личная страница + сообщество.

Community дает больше навигационных поверхностей: cover, action, menu, sections, pinned navigator. Personal page сильнее подчеркивает конкретного автора.

### Packaging job

VK может соединять:
- личный авторский профиль;
- рекомендации/охват оригинального контента;
- длинные тексты;
- клипы/видео;
- события/сообщество;
- удобную навигацию по материалам и проектам.

### Community first impression stack

1. Name
2. Avatar
3. Cover
4. Description/status
5. Primary action
6. Menu/sections
7. Pinned navigator
8. Recent original content

### Cover

Функция cover — не украшение, а быстрый контекст. Обычно достаточно:
- имя/проект;
- короткая смысловая опора;
- максимум один CTA, если он реально нужен.

Точные размеры/безопасные зоны проверяй по текущей справке VK перед передачей макета дизайнеру: публичные гайды 2026 содержат противоречащие друг другу размеры.

### Menu

Не делай меню ради меню. Каждый пункт должен отвечать реальному маршруту нового человека, например:
- С чего начать
- Медитация / практика
- Обо мне
- Встречи / события
- Лучшие материалы
- Связаться

Используй только те пункты, для которых есть содержимое.

### Pinned post

Закреп в VK может работать как мини-landing/navigation page:
- кто;
- о чем;
- кому может быть близко;
- как устроен профиль/сообщество;
- куда идти дальше.

## Instagram

### Current platform reality — September 2026

- Bio остается коротким полем; текущие свежие источники указывают лимит 150 символов.
- Instagram позволяет добавлять несколько external links; на профиле один получает приоритетное отображение, остальные раскрываются дополнительно.
- Name field используется как отдельная смысловая/search surface и не должен быть просто дублем username.
- До трех posts можно закреплять наверху профиля.
- С июня 2026 доступен `Reorder your grid`: пользователь может переставлять публикации и проектировать first-grid сознательно.
- С сентября 2026 Instagram начал rollout возможности добавлять posts, где пользователь отмечен, прямо в основной grid; это полезно для реальных коллабораций/социального proof, если такие материалы существуют.
- Story Highlights остаются поддерживаемым инструментом, но конкретное расположение/интерфейс меняется и может различаться между аккаунтами. Не строй всю упаковку на одном layout assumption.

### Packaging job

Instagram особенно силен как:
- discovery surface;
- быстрый first impression;
- визуальное доказательство личности;
- вход через Reels/carousels/posts к профилю;
- перевод интереса в follow, Telegram или другой один следующий шаг.

### First impression stack

1. Username
2. Profile photo
3. Name field
4. Bio
5. Primary link + CTA/category when applicable
6. Pinned posts
7. Curated first grid
8. Highlights/other profile surfaces when available

### Bio

Не пытайся вместить всю биографию.

Рабочая логика:

`понятный вход/территория → зачем следить → отличительный штрих → identity/source, если помогают пониманию → следующий шаг`

При очень коротком лимите один элемент может жить в name field, а другой — в pinned posts.

### Pinned 3

Default architecture, адаптируй по dossier:

1. **Лучший вход / value proof** — что здесь можно реально понять, попробовать или увидеть без предварительного контекста.
2. **Автор / почему слушать** — человек, путь и границы его опыта.
3. **Worldview/source / следующий слой** — идея через жизнь, источник и путь к более глубоким материалам.

Если цель коммерческая/событийная, один pinned может быть current offer/event, но не превращай все три в рекламу.

### Grid curation

Поскольку grid можно переставлять, проектируй первые 6–9 единиц как портфолио смыслов, а не как хронологию.

Они должны вместе показать:
- лицо/человека;
- ключевую тему;
- личную историю;
- прожитую практику;
- идею/позицию;
- social proof или реальный контекст;
- следующий шаг.

Не проектируй «идеальную шахматную сетку» ценой живого контента.

## Cross-platform rule

Нельзя делать:

`одна bio → вставить в TG + VK + IG`.

Нужно делать:

`одно ядро → три platform-native first impressions`.

Для каждой площадки отдельно реши, где живут cold entry, value proof, author identity, worldview/source и deep layer. Не копируй один и тот же порядок раскрытия автоматически.

Едиными держи:
- лицо/имя;
- центральную территорию;
- основные beliefs;
- tradition visibility;
- voice;
- визуальные константы.

Адаптируй:
- длину;
- навигацию;
- CTA;
- порядок доказательств;
- плотность терминологии;
- pinned/start-here architecture.
